# Security Policy

This is a company-private package. Report a suspected vulnerability through
the company’s approved internal security channel and include only the minimum
reproducible technical detail. Do not place tokens, activation codes,
certificates, private keys, customer data, raw device frames, or production
endpoints in issues, pull requests, logs, or release evidence.

Security fixes include a threat-boundary explanation, regression coverage, and
compatibility notes. Runtime policy and trust-material updates must be signed
and monotonic; the package never accepts remotely downloaded executable code.
